1. Audio Preprocessing
Resample to 16 kHz, mono channel

Truncate or pad to 12-second target duration

3-second sliding windows with 50% overlap

Training augmentation: pink noise (15-30 dB SNR, 50%), echo, gain perturbation

2. Acoustic Feature Extraction
Wav2Vec 2.0 Base encoder (12 transformer layers)

Layer-wise dimension-reduction modules (DRMs)

Attentive pooling with entropy weighting

Maxout activation and layer-specific classifiers

3. Text Feature Extraction
DistilBERT-base-uncased encoder

Tokenization with maximum 128 wordpieces

[CLS] token embedding for sentence-level summary

4. Bidirectional Cross-Modal Attention
Audio→Text cross-attention

Text→Audio cross-attention

Multi-head attention with 4 heads, latent dimension 256

Residual connections and layer normalization

Relevance gating for modality weighting

5. Multi-Task Learning
Task A: Nine-class emotion classification (cross-entropy + ArcFace)

Task B: Continuous activation/arousal regression (MSE)

Task C: Three-level proxy classification (aggregated from Task A)

6. Calibration
Temperature Scaling: Validation-only fitting for emotion probabilities

Variance-Aware Calibration: Platt scaling for regression uncertainties

7. Evaluation Protocol
Five-session Leave-One-Speaker-Out (LOSO)

Strict dialog-level splitting (no leakage)

Dedicated calibration partition (10%)

Fold-averaged and pooled held-out metrics
